
# Content-Based and Collaborative Filtering Movie Recommendation System

## Overview
An enhanced Movie Recommendation System implementing two machine learning recommendation techniques to provide personalized movie suggestions.

## Recommendation Techniques

### 1. Content-Based Filtering
Recommends movies based on movie characteristics such as genres and content similarity.

### 2. Collaborative Filtering
Recommends movies based on user rating patterns and similarities between users' preferences.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- TMDB API
- MovieLens Dataset

## Project Features
- Two recommendation techniques
- Interactive Streamlit application
- Movie posters using TMDB API
- Personalized movie recommendations
